Quel type d’opportunité recherchez-vous ?+

Je recherche un stage en analyse ou en ingénierie des données, dans le cadre de mon master à l’ESIGELEC. Écrivez-moi pour échanger sur votre projet et les possibilités.

Quels sont vos outils de prédilection ?+

Python et SQL pour préparer et analyser les données, Power BI pour les visualiser, ainsi que Spark et PySpark pour le Big Data.

Comment explorer vos projets ?+

Cliquez sur une carte pour découvrir son contexte, ses outils et ses réalisations. Le graphe de compétences permet de retrouver les projets associés à un outil.

D’où viennent les données du portfolio ?+

Le mode local reprend mon CV. Le bouton de configuration permet de connecter l’API FastAPI de l’équipe : MongoDB fournit le parcours et les projets, Neo4j les relations entre compétences et projets.

Comment vous contacter ?+

Mon e-mail et mon numéro sont dans la section Contact. Mon CV est disponible au téléchargement.
